# Текущий контекст работы над sfml-dungeon-gen

## Последние изменения (Сессия: Модульная архитектура и Движок)
- **Ядро генерации**:
  - Введен интерфейс `GeneratedObject`, задающий общий контракт для всех сущностей (геометрия, масса, метаданные, методы перемещения и отрисовки). Класс `Room` теперь наследует этот интерфейс.
  - Реализован паттерн Фабрика (`ObjectFactory`), позволяющий инстанцировать различные типы объектов на основе нового поля `"type"` (по умолчанию `"room"`) из конфига.
- **Физический движок**:
  - Алгоритмы `separateRooms` и `getCollisionMTV` (на базе SAT) полностью отвязаны от класса `Room` и переписаны для работы с коллекцией `std::shared_ptr<GeneratedObject>`.
- **Система конфигурации и Маски**:
  - Структура проходов генерации переименована из `RoomPassConfig` в `ObjectPassConfig`.
  - Введена поддержка визуальных масок спавна. Поле `"spawnMaskPath"` позволяет указать путь к изображению.
  - **Вероятностный спавн по маске**: Реализована логика, где вероятность появления объекта в точке зависит от яркости (градации серого) соответствующего пикселя маски. Белый (255) — 100% вероятность, черный (0) — 0%, серый — пропорционально яркости.
  - **Стабильность путей**: Исправлена ошибка, при которой конфиг создавался в некорректном месте из-за отсутствия папки. Добавлено автоматическое создание директорий через `std::filesystem`. Ведется работа по привязке путей к корню проекта, чтобы конфиги не дублировались в папках сборки (bin/build).

## Текущие задачи
1. **Глобальные пути конфигов**: Реализовать поиск корня проекта для хранения настроек в одном месте (`/generation_configs/` в корне).
2. **Визуальный стиль**: Подготовка к реализации шейдеров "масляной живописи" и системы "Пергамента".
Проект трансформирован из монолитного генератора в гибкий **"движок" процедурной генерации**. Вся логика развязана через интерфейсы и фабрики, что позволяет легко добавлять новые формы (например, круглые арены или колонны) простым расширением `GeneratedObject` и добавлением в `ObjectFactory`. Благодаря поддержке масок-изображений, контроль над формой подземелья стал максимально настраиваемым. Проект полностью готов к интеграции с другими C++ проектами (включая GamakEngine) в качестве модульной библиотеки.
